Network Connectivity Visualizer
(c) Matteo Golin 2026

DESCRIPTION:
    Visualize the connectivity of an ad-hoc network.

USAGE:
    netconn [OPTIONS] n m

OPTIONS:
    -h          Display this help text.
    -x <width>  Window width in pixels. Default is half screen width.
    -y <height> Window height in pixels. Default is half screen height.
    -s <scale>  Rendering scale. Default 5.
    -l <limit>  Path loss limit for severed connection in dB.
    -z <height> Fixed z-coordinate (altitude) of UAVs. Default 10.0 m.
    -r <seed>   Random seed to seed the random library with.

ARGUMENTS:
     n          Number of UAVs.
     m          Number of ground units.

CONTROLS:
    This game is visualized using SDL2 and accepts keyboard input.

    q           Quit the game.
    n           Show network connections.
    h           Show heatmap.
    w           Move selected UAV up.
    a           Move selected UAV left.
    s           Move selected UAV down.
    d           Move selected UAV right.
    c           Move UAVs to high scoring locations.
    Up          Select next UAV in the list.
    Down        Select previous UAV in the list.
    Esc         Quit the game.
    Space       Re-start the game.

    Mouse click: Move selected UAV to clicked point.
