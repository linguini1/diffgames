Molecules
(c) Matteo Golin 2026

DESCRIPTION:
    Ad-hoc aerial network formation inspired by molecules.

USAGE:
    molecules [OPTIONS] n m

OPTIONS:
    -h          Display this help text.
    -x <width>  Window width in pixels. Default is half screen width.
    -y <height> Window height in pixels. Default is half screen height.
    -s <scale>  Rendering scale. Default 5.
    -d <limit>  Distance loss limit for severed connection in meters. Default
                50.0 m.
    -z <height> Fixed z-coordinate (altitude) of UAVs. Default 10.0 m.
    -r <seed>   Random seed to seed the random library with.
    -m          If passed, ground units move randomly instead of being static.

ARGUMENTS:
     n          Number of UAVs.
     m          Number of ground units.

CONTROLS:
    This game is visualized using SDL2 and accepts keyboard input.

    q           Quit the game.
    r           Toggle network connection radii.
    n           Toggle network connection lines.
    Space       Reset the game.
    Esc         Quit the game.
